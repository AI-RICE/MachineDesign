This website contains the documentation for the [MachineDesign](https://github.com/AI-RICE/MachineDesign) project.

The aim of the project is to provide a library for designing barriers in electrical machines, from geometry and winding generation to simulation and optimization. The core functionality includes:

- computing and assigning winding layouts for different phases, slots, and pole combinations, see [Winding layout](WINDING.md).
- building and simulating machine models through Ansys Electronics Desktop (AEDT).
- optimizing rotor barrier geometry and current setpoints with Bayesian optimization.
