# Reference PDFs — `newparam` line

PDF archive for this line (separate from the PFN line's `../../overleaf`).

- Filename convention: `{firstauthor}{year}_{shorttitle}.pdf`, lowercase, ASCII
  (e.g. `hvarfner2024_vanillahdbo.pdf`).
- Add a PDF here when we **use** a paper (typically at H-REPL replication time),
  not for every surveyed candidate.
- Paywalled items with no open PDF: append one line to `paywalled.md`
  (`{firstauthor}{year} — {short title} — {URL}`); the user downloads manually.

Metadata for every archived PDF must be externally verified per **H-CITE**
([../README.md](../README.md)) before it is cited.
